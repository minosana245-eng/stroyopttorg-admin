# СтройОптТорг — Панель управления (Frontend)

Админ-панель для интернет-магазина строительных и хозяйственных товаров **ООО «Стройоптторг»**, разработанная на основе макета Figma `СтройОптТорг ~30000-45000`.

## Стек
- **React 19 + TypeScript**
- **Vite 6**
- **Tailwind CSS v4**
- **lucide-react**
- Хранение демо-данных: `localStorage` (`stroyopttorg_admin_v1`)

## Быстрый запуск
```bash
npm install
npm run dev
```

Приложение откроется по адресу `http://localhost:5173`.

## Сборка и предпросмотр продакшена
```bash
npm run build
npm run preview
```

Готовые статические файлы появятся в папке `dist/`. В `vite.config.ts` задан `base: './'`, поэтому сборка корректно работает как от корня домена, так и при размещении в поддиректории (например, на GitHub Pages).

## Структура проекта
- `src/pages/` — экраны разделов админ-панели и форма входа
- `src/components/` — общий макет (`AdminLayout`), логотип и UI-компоненты
- `src/store/useAdminStore.ts` — состояние и сохранение в `localStorage`
- `src/data/seedData.ts` — стартовые демо-данные каталога, заказов, клиентов и настроек
- `src/types/admin.ts` — TypeScript-типы моделей данных
- `src/utils/format.ts` — форматирование цен, дат и чисел

## Реализованные разделы
- **Дашборд** — KPI (масштаб 45 380 SKU, выручка, средний чек, звонки), график продаж, каналы доставки, последние заказы и активные промокоды.
- **Каталог и бренды** — 3-уровневое дерево категорий (*Мегаменю*), SEO-поля, атрибуты фильтров и справочник брендов.
- **Товары (SKU)** — поиск, фильтры, пагинация (`9/12/18/24`), массовые операции, импорт/экспорт CSV, редактор товара с характеристиками.
- **Заказы** — статусы (`ОБРАБОТКА`, `ВЫПОЛНЕН`, `ОТМЕНЕН`), заказы *В 1 клик*, СДЭК/Самовывоз, расчёт промо и скидок от суммы, печать счёта.
- **Клиенты (B2C/B2B)** — физлица и компании, адреса доставки, заметки менеджера.
- **Скидки и промо** — промокоды, шкала скидок от суммы корзины, симулятор расчёта корзины, акции и слайдеры.
- **Блог, отзывы, FAQ** — управление статьями, модерация отзывов и база FAQ.
- **Звонки и рассылка** — заявки *Заказать звонок* и email-подписчики с экспортом в CSV.
- **Настройки магазина** — реквизиты `ООО «Стройоптторг»` (ИНН/КПП/р/с/БИК), склад, города, доставка и способы оплаты.
